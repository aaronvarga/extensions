# Muxy Extensions

## PR

- Every PR should only version one extension
- PR title should be like `extension-name 1.0.1`

## Fork Workflow

This is a personal fork (`fork` remote). AI agents may commit and push here when asked.

Anything aimed at upstream (`origin`, muxy-app/extensions) stays human-only: opening PRs or issues there, or interacting with them (read-only allowed).
